# Module 3: Copy and Move Semantics (C++20)

Практическая работа по реализации Правила пяти (Rule of Five) и семантики перемещения.

## Что сделано
1. Реализован класс `Buffer`, управляющий сырым массивом `int*`.
2. Написаны все 5 методов:
   - Деструктор
   - Конструктор копирования (глубокое копирование)
   - Оператор копирующего присваивания (с проверкой на самоприсваивание)
   - Конструктор перемещения (`noexcept`)
   - Оператор перемещающего присваивания (`noexcept`)
3. В `main.cpp` продемонстрировано, что при `std::move` исходный объект обнуляется (`nullptr`), а данные переходят без копирования.
